### smoke/Q1: 用英文写一段产品说明，产品是团队协作工具。

A shared workspace for coordinating group work. Tasks, files, deadlines and comment threads sit on one board, so current status stays readable without a separate status meeting. Each assignment carries an owner and a due date, and discussion attached to a task preserves the decision record beside the relevant file. Access rules scope documents to named projects, and every edit enters an activity log with author and timestamp. Search spans tasks, comments and uploaded files. Calendar, chat and version-control integrations deliver updates into the same timeline. Workspace administrators invite members by email and set roles in the settings panel; no server deployment is required.
