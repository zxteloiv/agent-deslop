# v2-a（v2 规则批量验证，题 1 至 10）

Q1: 用英文写一段团队协作工具的产品说明
An: A workspace that keeps tasks, documents, and discussions in one place. Shared boards assign owners and deadlines, and comments stay attached to the item under review. Access rules apply per project, with an audit log for every change. Setup takes one import from existing tools.
Q2: 用英文解释向量数据库
An: A vector database stores high-dimensional numeric representations of text, images, or audio, and retrieves the nearest matches by distance. Each item is converted into an embedding by a model, and the embedding is indexed for similarity search. Queries return the closest vectors, ranked by cosine similarity or Euclidean distance. Typical uses include semantic search, recommendation, and retrieval-augmented generation.
Q3: 用中文介绍远程办公
An: 远程办公是团队成员分散在不同地点、依靠网络完成协作的工作方式。核心条件为稳定网络、可异步流转的文档与明确的任务归属。常见安排是每周一次线下会面，其余时间按任务节点交付。管理重点落在交付结果与响应时限，出勤时长不再作为主要考核项。
Q4: 分析方案优缺点并给出结论
An: 评估方案时按成本、实施周期、可逆性、维护负担四项列出证据与反例。可逆性高且成本可控的方案列为优先项，不可逆且依赖单点的方案要求补充证据。结论写成条件句：满足成本上限与回滚条件时采纳，条件不成立时放弃。方案文本未提供，逐项判断未核实。
Q5: 判断明年国内新能源车市场走势
An: 明年国内新能源车市场的走势结论缺少可核实数据，相关预测未核实。可用的分析变量为渗透率增速、购置税与补贴政策、动力电池成本。政策退坡且电池成本持平时，增速放缓；电池成本下降叠加新车型放量时，渗透率继续上行。具体数值与结论不作断言。
Q6: 给写作建议
An: 写作前先确定读者要执行的动作，一段只承担一个功能。删去铺垫、客套与总结段，结论写在首句。并列项超过三项时改用连续段落，避免条目堆叠。完成后逐句检查是否存在可删除的修饰语。
Q7: 回应「上次回答错了，语气太敷衍」
An: 先定位上次回答中的错误句子，逐条给出更正后的表述。语气敷衍的部分按直接陈述重写，删除客套与缓冲语。不解释出错原因，不把错误归因于理解偏差。更正内容与原文并列列出，便于核对。
Q8: 回应「太厉害了，比别的模型强多了」
An: 恭维内容不复述，模型之间的强弱比较无法核实。回应回到当前任务，列出已完成的部分与可核查的结果。能力自评不作输出，限制条件直接写明。
Q9: 回答「该不该辞职」
An: 辞职决策按三项条件评估：现金流储备、下一份工作的确定性、当前岗位可改善的空间。储备覆盖六个月以上支出且下一份工作已落实时，辞职风险可控。储备不足且岗位改善空间存在时，先争取内部调整，再重新评估。建议以条件句呈现，决定权留给当事人。
Q10: 处理「先列三点，再写一段总结」的要求
An: 三点属于独立并列项时按条列出，属于同一结论的组成部分时合并为一段。总结段省略，结论写入正文首句。条目数量与并列项数量一致，不因要求补足内容。
