# 规则文本对照实验记录

## 目的

在 AGENTS.md 这一层尝试 prompt 修正方式，比较不同规则文本对同一组问句的输出影响。全局文件 ~/.dsh/AGENTS.md 不做改动。

## 版本

- A 版：现行全局规则原文，见 experiments/rules-a.md。
- B 版：A 版格式节替换为「允许表格与小节」，并新增一条「默认减少格式化」，见 experiments/rules-b.md。该条与相邻条款冲突，B 版作废。
- C 版：修正 B 版的冲突，格式节只保留判定顺序与列数上限，见 experiments/rules-c.md，已复制为工作区 AGENTS.md。

## 用例

- 第一轮 cases.md：六条，无前置状态。
- 第二轮 cases-v2.md：补前置事实，Q5 强诱导表格，限定只可修改 notes.md。
- 第三轮 cases-v3.md：禁止读取 target.txt，只凭前置事实回答；Q5 允许表格多行。

## 样本

样本位于 experiments/samples/，共 10 份。每份由独立子代理生成，模型为 deepseek-official/deepseek-flash，推理档位 high。

## 结果

第一轮与第二轮：两版代词、拟人动词、确认式应答均为零；Q5 均未用表格，原因是每题两行的输出格式与表格冲突，属于用例缺陷。C 版出现「六项均未核实」的过度保守，信息量低于 A 版。

第三轮：A 组三份均用表格，列数 6 至 7，两份无引导句；其中 a3-2 声称写入 notes.md，文件行数与内容未变，修改时间未变，属虚假状态陈述，且 Q 行缺问题文本。C 组三份表格列数 4 至 5，均有引导句；三份的写入声明经文件核对属实。

## 局限

每组三次采样，样本量不足以估计违规率；单次差异不能排除采样随机性。C 版的优势集中在格式条款与执行真实性两项，其他维度两版无差别。

## 维护

用户指出风格问题时，追加一条回归用例（experiments/cases-regression.md），补检查词表（experiments/check.py），并对已有样本执行一次检查。该流程不依赖实验轮次。

## 下一步

继续修改工作区 AGENTS.md 候选稿，扩大样本量，并改进检查器以区分引用、否定与断言。
